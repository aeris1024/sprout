# Sprout GUI

Sprout GUIは、Tauri 2、React、TypeScript、Viteで構築したWindows向けデスクトップアプリです。
GUIは`.sprout`を直接操作せず、Rust側の共通IPCコマンドから`sprout <command> --json`を実行します。

## 必要な環境

- Windows 10または11とWebView2 Runtime
- Node.js 20.19以降
- pnpm
- Rust stable（MSVC toolchain）
- Visual Studio 2022のDesktop development with C++とWindows SDK
- PATH上のSprout CLI、またはGUIの「CLI設定」で指定する実行ファイル

リポジトリのルートからSprout CLIをインストールする場合は次を実行します。

```powershell
uv tool install .
sprout --help
```

Rustを初めて導入した直後は、ターミナルを再起動して`cargo`へのPATHを反映してください。

## 開発

`gui`ディレクトリで依存関係を準備し、Tauriの開発ウィンドウを起動します。

```powershell
cd gui
pnpm install
pnpm tauri dev
```

フロントエンドだけをブラウザで確認する場合は`pnpm dev`を使えます。ただし、フォルダ選択、設定保存、Sprout CLI呼び出しはTauriウィンドウ内でのみ動作します。

## 検証とビルド

```powershell
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri build
```

`pnpm tauri build`の成果物は`gui/src-tauri/target/release/bundle/`へ作成されます。

## 初回利用

1. PATHに`sprout`がない場合は、右上の歯車からCLIの実行ファイルを指定します。
2. 「プロジェクトを選択」、または上部バーのプロジェクト名から「フォルダを開く…」で作業フォルダを選択します。
3. 未初期化のフォルダでは、確認画面から`sprout init --json`を実行できます。

## 画面構成

画面は上部バー、中央の芽のマップ、右側のパネルの1画面です。狭いウィンドウでは右側のパネルがマップの下へ移ります。

- **上部バー**: プロジェクト名（クリックで最近使ったプロジェクトの切り替え・一覧からの削除・フォルダを開く）、現在のブランチ、保存状態（保存済み／未保存の変更の件数）、更新、ファイル、保存、設定（歯車）を表示します。
- **右側のパネル**: 何も選んでいないときは未保存の変更と保存フォームを表示します。メッセージと、必要なら2 MiB以下のPNG・JPEG・WebPサムネイルを指定して保存します。サムネイルはファイルを選ぶほか、このパネルを表示中にCtrl+Vでクリップボードの画像を貼り付けても指定できます（メッセージ欄へのテキスト貼り付けはそのまま入力されます）。途中のスナップショットから保存すると新しいブランチが自動で作られます。上部バーの「保存」とCtrl+Sでこのパネルを開きます。
- **葉の詳細**: 選んだ葉のメッセージ、日時、ブランチ、タグ、添付、ファイル数を表示し、「ここへ移動」「ここから枝を伸ばす」「サムネイルを登録・変更」「メッセージを編集」「ファイルを取り出す」を行えます。葉の詳細を表示中にCtrl+Vでクリップボードの画像を貼り付けると、その葉のサムネイルとしてすぐに登録・置き換えします。「ここへ移動」は確認なしで`sprout go`を実行し、未保存の変更は移動前の芽のつぼみとして残ります。移動後の現在位置・ブランチ・つぼみは1回の応答でマップと上部バーへ反映します。「ここから枝を伸ばす」は名前を付けた枝を作ってその芽へ移ります。
- **メモ・ラベル・タグ**: 葉の詳細の下部で編集します。メモは「メモを書く／メモを編集」から保存し、空にして保存すると削除します（20,000文字まで）。ラベルは入力して「追加」、チップの×で外します（1件64文字・1スナップショット32件まで）。タグはコメント付きで一覧し、名前とコメントを入力して「タグを付ける」、各タグの「編集」でコメントを変更、「削除」は確認後にタグだけを消します。CLIに拒否された場合は理由を通知し、入力内容はそのまま残ります。編集後はマップと詳細を取り直します。
- **ブランチの詳細**: 芽のマップの枝名、または上部バーの現在のブランチをクリックすると開きます。名前・コメント・枝先のスナップショット（クリックでその葉を開く）を表示し、名前の変更とコメントの編集（空にして保存すると消える）ができます。「ブランチを削除」は確認後に実行し、その枝のスナップショットは「削除済みブランチ由来」として残ります。現在のブランチは削除できません。名前を変えても同じブランチとして選択したままになり、CLIに拒否された場合は入力内容が残ります。
- **ブランチの表示**: ブランチはIDで識別します。葉やつぼみの詳細では、作成時から名前が変わったブランチを「現在の名前（作成時: 元の名前）」、削除されたブランチを「名前（削除済み）」と表示するため、同じ名前で作り直したブランチと混同しません。現在位置はCLIが記録した位置だけを使い、ブランチ先端から推測しません。
- **添付**: 葉の詳細に、サムネイルとpreviewを保存された表示順で、種類・元のファイル名・形式・サイズとともに一覧します。previewの追加や並べ替えはまだGUIからは行えません。
- **つぼみ**: 退避した変更は元の葉の下に「つぼみ N」として表示されます。最初の保存より前に退避したつぼみは地面の「はじまり」の横に並び、スナップショットがまだない場合はマップの中央に一覧されます。削除済みブランチで退避したつぼみは、戻しても今のブランチのままです。選ぶと変更ファイルを確認でき、「このつぼみに戻る」で作業フォルダをその状態へ戻します（今の未保存の変更は新しいつぼみとして残ります）。「つぼみを捨てる」だけは確認が表示されます。
- **未保存の芽**: 未保存の変更があると、現在位置の葉の上に点線の「未保存の芽」が出ます。選ぶと変更ファイルと保存フォームを表示します。途中の芽から保存する場合は、新しい枝が自動で作られることを保存前に表示します。
- 移動やつぼみの復元が未追跡ファイルとの衝突などで中止された場合は、理由と対象のパス、作業フォルダを変更していないことを通知します。
- **ファイルパネル**: 上部バーの「ファイル」で開き、追跡中・未追跡のファイル一覧、追跡と追跡解除を行います。ウィンドウへファイルやフォルダをドロップしても追跡できます。「追跡解除」は作業ファイルを削除しません。
- **芽のマップ**: 削除済みブランチ由来を含む全スナップショットを、古いものが下・新しいものが上になるよう茎と葉で表示します。葉は茎の左右に交互に付き、サムネイルとメッセージを表示します（サムネイルがない葉は無地）。ブランチは分岐元から横へ分かれて上へ伸びる枝で、ブランチ名は枝の先、タグは葉の札で示し（葉に収まらない長いタグ名は「…」で省略し、札にポインタを重ねると全体を表示）、現在のブランチを強調します。現在位置は青い枠と「いまここ」で示し、開いた直後や更新後は現在位置が見える位置へスクロールします。左上のボタンで50〜150%に拡大・縮小できます。葉・つぼみ・枝名はクリックまたはキーボード（Tab、Enter）で選択できます。同じ葉が複数のブランチの枝先なら、枝名は縦に並びます。まだ保存のない枝のように、茎の途中の葉が枝先のブランチは、葉と反対側へ出した点線の小枝の先に名前を表示し、茎と重ならないようにします（名前が長い場合はマップの左右に余白を取ります）。

ブランチ切り替えまたは復元が未保存変更によって拒否された場合だけ、追跡対象の変更を破棄して再実行する確認画面が表示されます。操作中は他の操作ボタンが無効になります。状態は「更新」で再取得します。

見た目は配色C「夜の温室」で、ライト/ダークはOSの設定に従います。色・角丸・余白・フォントは`src/App.css`冒頭のCSS変数に集約しているため、配色を変える場合はそこだけを差し替えます。

貼り付けた画像はOSの一時フォルダへ`clipboard.png`などの名前で書き出してから`sprout`へ渡し、登録後や解除・差し替え時に削除します。PNG・JPEG・WebP以外や2 MiBを超える画像は登録せず警告を表示します。

サムネイルはPNG・JPEG・WebPだけを画面内へ近づいた時点で読み込みます。取得結果はプロジェクト、コミットID、オブジェクトハッシュ、メディアタイプ単位でメモリへキャッシュされます。音声、動画、アニメーション画像、3Dモデルは自動再生・描画しません。

最近使ったプロジェクトとCLIパスは、Tauri StoreによりOSのアプリデータ領域へ保存されます。最近使った一覧の削除ボタンは保存された一覧だけを更新し、プロジェクトのフォルダーやSprout履歴、現在開いている画面を削除・終了しません。
Sprout CLIがロック中の場合は再試行ボタンを表示し、CLIが見つからない場合はCLI設定を開きます。

GUIはPATHまたは手動指定のCLIを`sprout serve`として1つだけ常駐させ、すべての操作をその常駐プロセスへJSON Linesで送ります。CLIの切り替え時は常駐プロセスを起動し直します。`serve`に対応していない古いCLIでは、従来どおり操作ごとにCLIを起動します。常駐プロセスが途中で終了した場合は、その操作を都度起動で実行し、次の操作で常駐プロセスを起動し直します。将来sidecarを同梱する場合も、Rust側の実行ファイル解決だけを差し替え、フロントエンドのIPC契約は維持します。
