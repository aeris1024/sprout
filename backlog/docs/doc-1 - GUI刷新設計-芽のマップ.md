# GUI刷新設計: 芽のマップ

関連タスク: TASK-51、TASK-73 / モックアップ: `gui/design/sprout-gui-final.html`（現在の見た目。右下でライト・ダークを切り替えられる）、`gui/design/sprout-map-mockup.html`（初版の検討用。縦に伸びるマップ）

状態: 承認済み（2026-10-28）

## 目的

- サムネイルを主役にし、Sproutらしい「芽が伸びる」見た目で全スナップショットを俯瞰できるようにする。
- スナップショット間を確認ダイアログなしで気軽に行き来できるようにする。
- 現在のツリー構造表示（インデント付き親子リスト）と5タブ構成は廃止する。

## 画面構成

1画面構成とする。

- 上部バー: ブランドマーク、プロジェクト名（クリックで最近使ったプロジェクト一覧）、現在のブランチ、保存状態（「保存済み」または「未保存の変更 N」）、ファイル、保存、設定（歯車）。
- 中央: 芽のマップ。
- 右側: 選択中の要素の詳細パネル（葉・つぼみ・未保存の芽で内容が変わる）。
- 狭いウィンドウでは詳細パネルをマップの下へ移す。

## 芽のマップ

- 古いスナップショットを左（根元）、新しいものを右（先端）に置き、茎が左から右へ伸びる。左端に根元の線を引く（TASK-73で縦向きから変更）。
- スナップショットは作成順に1つずつ列を持ち、「葉」として茎の上に付く。葉はサムネイルを表示し、下にメッセージを添える。サムネイルがない葉は同じ大きさの無地で「画像なし」と表示する。
- ブランチは「枝」で、ブランチごとに横の行を持つ。過去の芽から分かれた枝は分岐元の芽から曲線で下の行へ降り、同じく右へ伸びる。茎の色はブランチごとに変える。
- ブランチ名は枝先の右に表示し、現在のブランチを強調する。途中の芽を指すブランチ名は、その芽の下（つぼみの下）に左寄せで吊るす。分岐の曲線は芽の右へ出るので、芽の下に置くもの（つぼみ・吊るしたブランチ名）は左側に寄せる。
- タグは葉の左上の札（`#提出` など）で表示する。
- 現在位置（作業ツリーが基づいている芽）は青い枠と「いまここ」の札で示す。
- 選択中の葉は実線の枠と「選択中」の札で示す。点線は使わない。
- 未保存の変更があると「未保存の芽」を表示する。琥珀色の実線の枠と「未保存 · N件の変更」の帯で示し、点線は使わない。現在のブランチの枝先にいるときはその茎の次の列に、途中の芽にいるとき（保存すると新しい枝になるとき）は現在位置の芽から曲線で分かれた新しい行に置く。
- 退避した変更（つぼみ）は、退避元の芽の下に「つぼみ N」の札として並ぶ。
- 開いた直後と移動の後は、現在位置が見えるようにスクロールする。
- 件数が多い場合の古い区間の折りたたみは後続で検討する。

## 詳細パネル

| 選択対象 | 表示 | 操作 |
|---|---|---|
| 葉 | サムネイル、メッセージ、日時、ブランチ、枝先か、タグ、ファイル数 | ここへ移動 / ここから枝を伸ばす / サムネイルを登録・変更 / ファイルを取り出す / メッセージを編集 |
| つぼみ | 退避元の葉、変更ファイル数、退避日時 | このつぼみに戻る / つぼみを捨てる（確認あり） |
| 未保存の芽 | 変更ファイル一覧 | メッセージとサムネイル（任意）を入力して保存。途中の芽にいるときは新しい枝ができることを示す |

## 操作と振る舞い

### 移動

- 「ここへ移動」で作業ツリーをその芽の内容にし、現在位置をその芽にする。
- 移動先が現在のブランチの先端なら現在のブランチのまま、他のブランチの先端ならそのブランチへ切り替える。途中の芽ならブランチは変えず、現在位置だけを移す。
- 確認ダイアログは出さない。未保存の変更はつぼみへ自動退避する。

### つぼみ（未保存の変更の自動退避）

- 未保存の変更があるまま移動すると、追跡ファイルの状態を確認なしで「つぼみ」として退避し、移動前の現在位置の葉に付ける。
- つぼみを選んで「このつぼみに戻る」と、作業ツリーを退避時の状態へ戻し、現在位置を退避元の芽にする。その時点で別の未保存の変更があれば、それも先につぼみへ退避する。戻したつぼみは書き戻し完了後に消す。
- 1つの芽に複数のつぼみを付けられる。捨てるときは確認する。
- つぼみの実体は既存のobjectsストアへ保存し、重複排除を共有する。gc・doctor・statsはつぼみの参照を考慮する。
- 未追跡ファイルは削除・上書きしない。移動先と衝突する未追跡ファイルやリンクがある場合は移動を中止する現行の保護を維持する。

### 保存

- 現在位置がブランチの先端なら、そのブランチへ葉を追加する。
- 現在位置が途中の芽なら、その芽を起点とする新しいブランチを自動作成して葉を付ける。ブランチ名は自動で付け（例: `枝-1027-2348`、形式は実装タスクで決める）、後から変更できる。
- 上部バーの保存ボタンとCtrl+Sで未保存の芽の詳細パネルを開く。

### 既存機能の配置

| 機能 | 新しい配置 |
|---|---|
| 最近使ったプロジェクト | 上部バーのプロジェクト名から開く一覧、プロジェクト未選択時の初期画面 |
| 初期化 | 未初期化フォルダを開いたときの画面 |
| CLI設定 | 歯車 |
| 変更一覧・コミット作成 | 未保存の芽の詳細パネル |
| 追跡・追跡解除・未追跡一覧 | 上部バーの「ファイル」パネル。ウィンドウへのドロップで追跡する動作は維持 |
| サムネイル登録・メッセージ編集 | 葉の詳細パネル |
| 復元 | 葉の「ここへ移動」 |
| ブランチ作成 | 葉の「ここから枝を伸ばす」 |
| ブランチ切り替え | 枝先の葉、またはブランチ名 |
| 履歴タブ・ステータス件数 | 廃止（マップと上部バーで代替） |

ブランチ作成時のコメント入力は、ブランチを保存時に自動作成する方式へ変わるため初版では廃止し、ブランチ名から開くメニューで扱う。メモ・ラベル・タグの編集、ブランチのリネーム・削除・コメント編集は初版に含めず後続タスクとする。

## 見た目

- 「朝霧」（ライト）と「夜霧」（ダーク）（TASK-73で決定、2026-10-30）。OSの設定に追従する。
  - 朝霧: 青みのある薄いグレーの背景に白いカードと細い枠線。
  - 夜霧: 青みのある濃いスレートグレー。朝霧と同じ青みで、切り替えても同じアプリに見える。
- 意味づけ: 現在位置は青、未保存の芽とつぼみは琥珀色。ブランチの茎は5色（`--branch-1`〜`--branch-5`）を順に使う。
- 札（タグ・「いまここ」）は淡い色に濃い太字。ダークでは茎と同じ明るい色に暗い文字。
- マップ上の葉のサムネイルは少し控えめにする（ライトは彩度をわずかに落とし、ダークは少し暗くする）。`--thumb-filter`で切り替える。
- 経緯: 初版はA案「植物ノート」→B案「ミニマル」→C案「夜の温室」と検討してC案に決めた（2026-10-28）。その後、横に伸びるマップ・未確定の表し方・ブランチの描き方・詳細の出し方・ダーク版の比較を経て朝霧と夜霧に変えた（2026-10-30）。詳細は従来どおり右のパネルに出す。
- 後から見た目を変えやすくするため、色・角丸・余白・フォントはテーマ用のCSS変数に集約し、コンポーネントに色を直書きしない。

## 応答速度

計測（Windows 11、追跡ファイル20件・計40 MB、コミット30件、中央値）: CLI起動のみ232 ms、restore 1173 ms、status 433 ms、log 270 ms、branch 303 ms、tree 365 ms。現在のGUIの復元1回は体感約2.0秒。

- 新しい移動コマンド`sprout go`は、退避・移動に加えて移動後の現在位置・変更有無などを1回の応答で返し、移動1回につきCLI呼び出しを1回にする。
- TASK-26（serve常駐モード）を新GUIの実装より前に行う。
- 追跡ファイルのハッシュ計算をサイズ・更新日時の記録で省略する高速化を独立タスクで行う。
- 目標: 一般的な規模のプロジェクトで芽の移動を1秒以内に完了し、GUIはクリック直後に選択表示を更新する。

## 必要なCLIの変更

現行CLIは、restoreが作業ツリーを書き戻すだけで現在位置を記録せず、commitは常にブランチ先端を親にする。そのため次を追加する。保存形式は正式リリース前のVersion 1のまま拡張し、移行処理は設けない。

1. 現在位置の記録: restore・switch・commitで更新し、status・treeのJSONで返す。
2. つぼみ: 作成・一覧・復元・破棄。gc・doctor・statsが参照を考慮する。
3. 移動コマンド（`sprout go <コミット>`）: つぼみへの退避と移動を一括で行い、中断時に復旧できる。移動後の状態をまとめて返す。
4. 途中の芽からの保存: 自動でブランチを作成して葉を付ける。
