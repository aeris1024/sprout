## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ブランチの名前変更・削除・コメント変更はCLIで行えるが、GUIにはブランチを選ぶ入口も操作もなく、ブランチのコメントも表示されない。

芽のマップや上部バーからブランチを選び、ブランチの情報確認と名前変更・削除・コメント編集を行えるようにする。ブランチはIDで識別し、CLIには現在の名前を渡す。

対象外: ブランチの切り替え専用UI、削除済みブランチの復活。
<!-- SECTION:DESCRIPTION:END -->

- [x] #2 ブランチの名前を変更でき、空・空白を含む・既存のブランチやタグと重複する名前はエラーとして通知され入力内容が失われない

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. MapSelectionにブランチ（kind: branch、ID）を追加し、芽のマップの枝名の札をブランチごとに選択できるボタンにする。上部バーの現在ブランチ表示もボタンにして現在のブランチを開く。
2. BranchPanelを追加し、名前・コメント・枝先のスナップショット・現在のブランチかを表示する。名前変更とコメント編集のフォーム、現在でないブランチの削除ボタンを置く。
3. AppはブランチIDから現在の名前を引いてbranch --rename・--set-comment・--deleteを呼ぶ。削除は確認ダイアログでスナップショットが削除済みブランチ由来として残ることを説明する。成功後にstatusとtreeを取り直し、同じIDで選択を保つ（削除時は選択を解除）。失敗時は入力を保持する。
4. 枝先から葉を開けるようにし、GUIテストで各操作・エラー時の入力保持・削除確認・名前変更後の同一性を確認する。gui/READMEを更新し、vitest・tsc・vite build・pytestで検証する。

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
## 実装

MapSelectionにブランチ（IDで識別）を追加した。芽のマップの枝名の札は、同じ葉が枝先の各ブランチを個別のボタンとして縦に並べる。上部バーの現在ブランチ表示もボタンにし、現在のブランチを開く。

BranchPanelを追加し、名前・コメント・枝先のスナップショット（クリックで葉を開く）・IDを表示する。名前変更、コメント編集（空で削除）、ブランチ削除を行える。現在のブランチは削除ボタンを無効にし、理由を表示する。AppはブランチIDから現在の名前を引いてbranch --rename・--set-comment・--deleteを呼び、成功後にstatusとtreeを取り直す。選択はIDで保持し、削除やtreeから消えた場合は選択を解除する。削除前の確認で、スナップショットが削除済みブランチ由来として残ることを説明する。編集が拒否された場合は入力を残す（TASK-64のexecuteの戻り値を利用）。
