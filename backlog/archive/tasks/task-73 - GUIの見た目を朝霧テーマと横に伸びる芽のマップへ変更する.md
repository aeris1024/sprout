## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
見た目の検討（2026-10-29〜30、モックアップで比較）で、承認済みのdoc-1の見た目から次へ変えることに決めた。縦に伸びるマップは横長のウィンドウで余白が多く、ブランチが増えると追いにくい。また、選択中の葉と未保存の芽がどちらも点線で表され、選んだだけの葉まで未確定に見えていた。色は将来また変えられるよう、テーマ用のCSS変数に集約したままにする。決定内容: 配色はライトが朝霧（青みのある薄いグレー、白いカードに細い枠線）、ダークが夜霧（青みのある濃いスレートグレー）でOSの設定に従う。マップは古いものが左（根元）、新しいものが右で、ブランチは行ごとに横へ伸び、分岐は曲線で下の行へ降りる。札（タグ・いまここ）は淡い色に濃い太字。マップ上のサムネイルは少し控えめ（ダークは暗く、ライトは彩度を少し落とす）にし、詳細パネルでは元の色で見せる。未保存の芽は琥珀色の実線枠と「未保存 · N件の変更」の帯、選択中の葉は実線枠と「選択中」の札で示し、点線は使わない。詳細は現在どおり右のパネル。
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
横向きのレイアウトは列=作成順（1スナップショット1列）、行=ブランチ。未保存の芽は、現在のブランチの枝先にいるときは同じ行の次の列、それ以外（途中の芽、別ブランチが指す芽）は現在の行の直後に一時的な行を挟んで曲線で分ける。保存時に新しいブランチになるCLIの振る舞いに合わせた。
長いブランチ名が左端からはみ出すときは全体を右へずらす（従来の縦向きと同じ考え方）。
確認: pnpm test（4ファイル）とpnpm buildが成功。サンプルのグラフでSproutMapを描く一時ページをviteで開き、ライト/ダーク、枝先にいる場合と途中の芽にいる場合を目視確認した（一時ファイルは削除済み）。
未確認: 実際のサムネイル画像での控えめ表示（ブラウザではTauri経由の画像を読めない）と、Tauriアプリでの上部バー・詳細パネルとの組み合わせ。

ユーザーがTauriアプリで実際のサムネイルの控えめ表示と、上部バー・詳細パネルとの組み合わせを確認し、問題なしとした（2026-10-30）。
<!-- SECTION:NOTES:END -->
