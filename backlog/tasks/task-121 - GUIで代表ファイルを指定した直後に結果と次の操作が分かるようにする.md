## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
「サムネイル自動生成元に設定」を実行しても今ある葉は変わらず、マップにも変化が出ないため、失敗したように見える。実際のプロジェクトでも、サムネイル自動生成元の指定は成功しているのに、保存も既存の葉への適用も行われていなかった。適用の操作はファイルパネルに小さく出るだけで、流れの中で案内されない。「サムネイル自動生成元に設定」は画像以外の行にも表示され、その分パス名も短く省略される。登録済みのサムネイルが変わらないことも画面から分からない。
用語はTASK-125.12で確定した「サムネイル自動生成元」にそろえる。このタスクの既存の機能範囲は維持する。

適用対象の件数は、サムネイル未登録の葉の総数ではなく、サムネイル自動生成元から実際に生成できる葉をapplyのdry-runで確認した結果に基づく。生成元がその葉にない、未対応、読み取り不可等のスキップと、登録済みで維持する葉を区別して案内する。TASK-125.12の正規サムネイル操作を使用し、TASK-123で対応形式が増えた場合も共通の対応形式に従う。
<!-- SECTION:DESCRIPTION:END -->

- [x] #5 適用後はマップに新しいサムネイルが表示される
