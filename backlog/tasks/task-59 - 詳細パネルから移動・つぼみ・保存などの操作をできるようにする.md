## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 背景

GUI刷新（doc-1、TASK-51で承認済み）では、芽のマップで選んだ葉・つぼみ・未保存の芽に応じて右側の詳細パネルの内容が変わり、確認ダイアログなしでスナップショット間を行き来できるようにする。

## ゴール

葉・つぼみ・未保存の芽それぞれの詳細表示と操作を実装する。移動はgoコマンド（TASK-54）、退避と復元はつぼみ、保存は途中からの自動ブランチ作成に対応したCLIを使う。
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
既存の`sprout move`（追跡ファイルの移動）と名前が重なるため、スナップショット間を移動する新コマンドの名前をgoに決定した（2026-10-28 ユーザー決定）。

## 実装と検証（2026-10-28）
- 選択をcommit/bud/unsavedの3種類で管理。葉の詳細（CommitPanel）に、ここへ移動（sprout go）・ここから枝を伸ばす（go後にbranch NAME COMMIT --switch）・サムネイル登録/変更・メッセージ編集・ファイルを取り出す（export、フォルダ選択）を配置し、旧「復元」「ブランチへ切り替え」は廃止。
- ここへ移動は確認なしで実行し、goの応答（現在位置・ブランチ・先端か・作成したつぼみ・変更一覧）だけでマップと上部バーを更新（追加のstatus/tree呼び出しなし）。葉のクリック直後に選択表示を更新。
- マップにつぼみ（元の葉の下）と未保存の芽（現在位置の葉の上）を表示。BudPanelで戻る（bud --restore）・捨てる（確認のみ）。SavePanelは現在位置が先端以外のとき新しい枝ができることを表示。上部バーの保存とCtrl+Sで未保存の芽の保存フォームを開く。
- go/つぼみの復元が拒否されたときは、理由・対象パス・作業フォルダを変更していないことを通知。CLI側で未追跡ファイル衝突のエラーにcode=untracked_conflictとdetails.pathを追加し、exportに--jsonを追加。goは書き戻し後に作業ツリーを再ハッシュせず変更なしを返すよう軽量化。
- 速度: TASK-51と同じ条件（追跡20件・計40 MB・30コミット）でsprout serve経由のgoを6回計測し、998/759/770/783/783/835 ms（中央値783 ms、従来GUIの約2.0秒から短縮）で1秒以内。
- 検証: pnpm test 36 passed（移動・衝突通知・つぼみ・未保存の芽・Ctrl+S・枝を伸ばす・書き出しのテストを追加）、tsc成功、pytest 263 passed / 19 skipped、Vite上でつぼみと未保存の芽の表示を確認。
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
詳細パネルから、確認なしの移動（未保存の変更はつぼみへ自動退避）、名前付きの枝の作成、サムネイル・メッセージ編集、ファイルの取り出しを行えるようにした。マップにつぼみと未保存の芽を表示し、つぼみへの復帰・破棄、未保存の芽からの保存（途中からは新しい枝の作成を事前表示）、上部バーとCtrl+Sからの保存に対応。移動はgoの1応答で画面を更新し、計測で中央値783 msと1秒以内を確認した。GUIテスト36件、Pythonテスト263件成功。
