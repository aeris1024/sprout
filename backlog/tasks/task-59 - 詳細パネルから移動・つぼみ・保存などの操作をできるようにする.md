## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 背景

GUI刷新（doc-1、TASK-51で承認済み）では、芽のマップで選んだ葉・つぼみ・未保存の芽に応じて右側の詳細パネルの内容が変わり、確認ダイアログなしでスナップショット間を行き来できるようにする。

## ゴール

葉・つぼみ・未保存の芽それぞれの詳細表示と操作を実装する。移動はmoveコマンド、退避と復元はつぼみ、保存は途中からの自動ブランチ作成に対応したCLIを使う。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 葉の詳細にサムネイル、メッセージ、日時、ブランチ、タグ、ファイル数が表示され、ここへ移動・ここから枝を伸ばす・サムネイルの登録と変更・メッセージ編集・ファイルの取り出しができる
- [ ] #2 ここへ移動は確認ダイアログを出さず、未保存の変更があれば移動前の芽につぼみとして退避され、マップと上部バーが1回の応答で更新される
- [ ] #3 クリック直後に選択表示が更新され、TASK-51と同じ条件で移動が1秒以内に完了する
- [ ] #4 つぼみが退避元の葉に表示され、選ぶと戻る・捨てるができ、捨てるときだけ確認される
- [ ] #5 未保存の変更があると現在位置の葉に未保存の芽が表示され、選ぶと変更ファイル一覧と、メッセージとサムネイルを入力する保存フォームが出る
- [ ] #6 途中の芽から保存すると新しい枝ができることが保存前に示され、保存後は新しい枝と葉がマップに表示される
- [ ] #7 上部バーの保存ボタンとCtrl+Sで未保存の芽の保存フォームが開く
- [ ] #8 移動やつぼみの復元が未追跡ファイルの衝突などで中止されたとき、理由と対象パスが表示され、作業ツリーが変わっていないことが分かる
- [ ] #9 各操作のGUIテストがある
<!-- AC:END -->
