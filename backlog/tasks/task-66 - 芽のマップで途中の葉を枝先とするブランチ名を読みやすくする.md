## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
スナップショットをまだ保存していないブランチ（途中の葉から作ったばかりの枝など）は、枝先が他のブランチの茎の途中の葉になる。現在の芽のマップは枝名を常に葉の真上へ置き、点線で葉と結ぶため、名前と点線が茎に重なって読みにくい。また、どの葉から伸びた枝なのかも分かりにくい。

茎の途中にある葉を枝先とするブランチ名を、茎と重ならない位置に表示し、その葉から伸びたまだ空の枝であることが分かるようにする。
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. layoutSproutMapで、各ブランチの枝先の葉がその茎の最上部かどうかを判定する。最上部なら従来どおり葉の上に名前を置き、途中の葉なら葉と反対側へ短い点線の小枝を出し、その先に名前を置く（placement: side）。同じ葉に複数ある場合は縦に並べる。
2. 横に置く名前の幅を見積もり、左端で切れる場合はレイアウト全体を右へずらし、右端ではマップの幅を広げる。
3. SproutMapで横置きの名前を描画し、個別の選択・キーボード操作・現在のブランチの強調を従来と同じにする。
4. レイアウトとGUIのテスト、gui/READMEの更新、確認用ブリッジでの実データ表示の確認、vitest・tsc・vite buildで検証する。

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
## 実装

layoutSproutMapで各茎の最上部の葉を判定し、そこを枝先とするブランチ名は従来どおり葉の上に置く（placement: top）。茎の途中の葉を枝先とするブランチ名は、葉と反対側へ短い点線の小枝と小さなつぼみの印を出し、その先に置く（placement: side）。1つの行には葉が1枚しかないため、反対側は空いている。同じ葉に複数の名前がある場合は、小枝の先に縦に中央揃えで並べる。横置きの名前の幅を全角を考慮して見積もり、左端で切れる場合はレイアウト全体を右へずらし、右側に余白が足りない場合はマップの幅を広げる。名前は従来と同じボタン（クリック・Enter）で、現在のブランチの強調と『（現在のブランチ）』の表記を共通の関数で維持する。
