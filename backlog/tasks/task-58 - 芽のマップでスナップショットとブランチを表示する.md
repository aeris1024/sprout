## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 背景

GUI刷新（doc-1、TASK-51で承認済み）では、現在のインデント付きツリー表示をやめ、下から上へ茎が伸びる「芽のマップ」で全スナップショットを俯瞰する。

## ゴール

全スナップショットを、古いものが下、新しいものが上になるよう茎と葉で描画する。ブランチは茎の途中から分かれる枝として描き、サムネイル・タグ・現在位置を表示する。葉を選ぶと詳細パネルに選択状態が伝わる。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 古いスナップショットが下、新しいものが上に並び、茎が下から上へ伸びる
- [ ] #2 スナップショットが葉として茎の左右に交互に付き、サムネイルとメッセージが表示され、サムネイルがない葉は同じ大きさの無地で表示される
- [ ] #3 ブランチが分岐元から分かれて上へ伸びる枝として描かれ、削除済みブランチ由来のスナップショットも欠けずに表示される
- [ ] #4 ブランチ名が枝の先、タグが葉の札として表示され、現在のブランチが強調される
- [ ] #5 TASK-52の現在位置が青い枠で示され、開いた直後と更新後に現在位置が見える位置へスクロールする
- [ ] #6 葉をクリックまたはキーボードで選択でき、選択が詳細パネルへ伝わる
- [ ] #7 数百件のスナップショットでも表示とスクロールが滞らず、サムネイルは表示範囲に近いものから読み込まれる
- [ ] #8 スナップショットが多い場合に拡大・縮小または古い区間の折りたたみで全体を把握できる
- [ ] #9 旧コミットツリー表示が削除され、レイアウトと選択のテストがある
<!-- AC:END -->
