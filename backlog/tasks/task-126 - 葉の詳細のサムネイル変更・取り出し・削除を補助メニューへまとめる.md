## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
葉の詳細パネルには移動・ブランチ作成に加えて、サムネイル登録/変更・ファイル取り出し・葉の削除が常時並んでおり、主要な操作が見分けにくい。TASK-101で行った詳細の並び・移動リンク・幅変更の改善に続き、補助操作の入口を整理する。

確定した方針:
- サムネイルの登録/変更、ファイルを取り出す、この葉を削除を、葉の詳細の補助メニューへまとめる。
- ここへ移動とブランチを作るは、詳細の先頭付近でメニューを開かずに直接使える位置へ残す。
- メニュー化は入口の整理であり、各操作の現在の機能・対象・確認・キャンセル時の動作を維持する。サムネイル未設定時の登録も同じ入口から利用できる。
- 比較やメッセージ編集など他の機能の削減、CLI体系変更、DB変更はこのタスクに含めない。TASK-125のCLI再編とは独立したGUI改善として扱い、作業時点の呼び出し契約と整合させる。

狭いパネルでも補助メニューを見つけて操作でき、マウスとキーボードで使えること。TASK-101の各節への移動・パネル幅変更を維持する。今回の依頼はBacklogへの登録のみであり、実装は別途着手する。
TASK-108のEscと整合し、補助メニューを閉じる1回のEscで親の葉詳細や編集中フォームまで閉じない。TASK-88でサムネイル自体の削除を追加する場合も、この補助メニューへ収めて葉そのものの削除と区別する。本タスクだけでは未実装のサムネイル削除を追加しない。
<!-- SECTION:DESCRIPTION:END -->
