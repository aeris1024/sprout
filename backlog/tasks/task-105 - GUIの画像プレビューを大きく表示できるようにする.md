## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 背景

葉には複数のプレビューを登録できる（例: 3Dモデルを多方向から見た画像）。今は、それを見るには右パネルで葉の詳細を開き、プレビュー欄まで移動して「画像を表示」を1件ずつ押す必要がある。表示は右パネルの幅に収まる大きさだけで、1200×1600の画像が249×333で表示され、拡大もできない。細部の確認には取り出しが必要になる。なお、マップの葉に表示されているのはサムネイル（role=thumbnail）で、プレビューではない。

## ゴール

マップの葉から直接、ウィンドウの大半を使うモーダルのビューアーを開き、その葉のプレビューを表示順に切り替えながら見られるようにする。詳細パネルのプレビュー欄からも同じビューアーを開ける。

## 決定事項

- 開き方: 葉のダブルクリックと、葉にキーボードの位置があるときのSpace（Quick Look風）。Enterは今までどおり選択。比較の相手を選んでいる最中も開ける。
- ビューアーに出すのはプレビュー（role=preview）だけで、サムネイルは含めない。プレビューのない葉では開かずに知らせる。
- 画像以外のプレビューも表示順のまま並べ、ファイル情報と取り出し操作のカードを出す。アプリ内での再生・表示（TASK-39/40/41）と関連アプリで開く操作（TASK-103）は範囲外。
- 等倍の意味: 現行の画像表示APIは原本上限とは別に表示用画像を長辺2048px以内へ縮小する。ここでの等倍は取得した表示用画像の1ピクセルを画面の1ピクセルで示すこととし、原本が既に縮小されている場合は原本等倍と表示せず、その寸法と縮小済みであることを明示する。原本のデコード上限を超える取得や、新たな原本フル解像度経路をこのタスクの暗黙の要件にしない。
- 順序はTASK-125.13の葉全体のプレビュー一覧の順序とし、代表指定・素材関連付けを表示条件にしない。
<!-- SECTION:DESCRIPTION:END -->

- [x] #4 ←/→キーと前後のボタンで表示順に切り替えられ、現在位置（例: 2 / 5）と名前の一覧を表示する。名前の一覧のために画像を読み込まない

- [x] #10 自動テストで、マップとパネルからの起動、切り替え、等倍の切り替え、Escでの閉じ方、プレビューのない葉、画像以外のカードを検証し、gui/README.mdを更新する

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. gui/src/lib/previewImages.ts: leaf preview image の取得を直近8件のLRUで共有し、同時要求をまとめる。
2. gui/src/components/PreviewViewer.tsx: body直下のモーダル。表示順の前後切替(←/→・ボタン)、位置表示、名前の一覧、合わせる/等倍(devicePixelRatioを考慮)の切替、画像以外と読込失敗のカード(取り出す)、Esc/×/背景で閉じてフォーカスを戻す、キー操作を外へ出さずTabを閉じ込める。
3. App.tsx: viewer状態(commitId, startId)を持ち、グラフの添付から表示順のプレビューを渡す。操作中は開かず通知、プレビューなしは警告を通知。葉や添付が消えたら閉じる。
4. SproutMap: 葉のダブルクリックとSpaceでonOpenPreviews。Enterは選択のまま。葉の印にプレビュー件数。
5. PreviewPanel: 各プレビューに「大きく表示」を追加し、そのプレビューから開く。
6. テスト(Viewer単体・Map・Panel・Appの起動とEsc)とgui/README.md更新、実機確認。

## Implementation Notes

- SproutMap: 葉のダブルクリック・Spaceで開く（Enterは選択のまま）。葉の印にプレビュー件数。PreviewPanel: 「大きく表示」とパネル内画像のクリックで開く。
