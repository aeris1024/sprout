## 背景

GUI刷新（doc-1、TASK-51で承認済み）では、5タブと左サイドバーの構成を廃止し、上部バー・芽のマップ・詳細パネルの1画面にする。見た目はC案「夜の温室」で、ライト/ダーク両対応とし、後から配色を差し替えられるようにする。応答速度のため、CLI呼び出しはTASK-26のserve常駐モードを使う。

## ゴール

新しい画面の骨格とテーマ基盤を作り、プロジェクトを開く・初期化する・最近使ったプロジェクト・CLI設定の既存機能を新しい配置へ移す。芽のマップ本体（後続タスク）を差し込める領域を用意する。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 画面が上部バー、中央のマップ領域、右側の詳細パネルの1画面で構成され、5タブと左サイドバーが廃止されている
- [ ] #2 色・角丸・余白・フォントがテーマ用CSS変数に集約され、C案のライトとダークがOS設定に追従して切り替わり、コンポーネントに色が直書きされていない
- [ ] #3 上部バーにプロジェクト名、現在ブランチ、保存状態、ファイル、保存、設定が表示される
- [ ] #4 プロジェクト名から最近使ったプロジェクトを選んで開け、一覧から削除でき、未選択時の初期画面にも一覧が表示される
- [ ] #5 未初期化フォルダを開いたときに初期化画面が表示され、初期化できる
- [ ] #6 CLI設定が歯車から開け、保存できる
- [ ] #7 GUIのCLI呼び出しがserve常駐モード経由になり、serveを起動できない場合はエラーを表示するか従来の都度起動へ戻る
- [ ] #8 狭いウィンドウでは詳細パネルがマップの下へ移る
- [ ] #9 移した既存機能のGUIテストが新しい構成に合わせて更新されている
