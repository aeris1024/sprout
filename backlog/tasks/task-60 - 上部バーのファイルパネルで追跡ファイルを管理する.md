## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
上部バーのファイルパネルによる追跡対象管理を確認し、不足する動作を補う。FilePanelとAppにはファイル/フォルダ追加、追跡/追跡解除、表示中パネルに応じたドロップ処理が既にあるため、旧ステータスタブからの移設を新規にやり直さない。
既存の一覧・件数通知・0件時の警告とテストを受け入れ条件に照らして検証する。コードが存在するだけでは完了とせず、未確認の動作や不足があればこのタスクで補う。
ドロップはTASK-97で確定した表示中パネルの規則に従う。ファイルパネル等の追跡追加先でのみ追跡し、葉詳細ではプレビューへ、ゴミ箱/比較/設定等では受け付けない。TASK-102の検索/ツリー、TASK-90の改名移動、TASK-121の自動生成元案内は別の改善範囲。

完了済みの基盤: TASK-57は完了/アーカイブ済み。実行待ちの依存には含めず、この本文から経緯を参照する。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 上部バーのファイルからパネルを開閉でき、追跡中と未追跡のファイル一覧が表示される
- [ ] #2 パネルからファイルとフォルダを追跡・追跡解除でき、結果件数が通知される
- [ ] #3 表示中のファイルパネル等が追跡追加先のとき、ファイル/フォルダのドロップで追跡され状態が更新される。葉詳細ではプレビュー追加等、TASK-97の振り分けを維持する
- [ ] #4 追跡対象が0件のときなど結果がない操作で警告が表示される
- [ ] #5 パネル操作とドロップのGUIテストがある
<!-- AC:END -->
